## Описание проекта

Программа на C++, реализующая собственный шаблонный класс `Vector`, который представляет динамический массив элементов произвольного типа.

Класс поддерживает добавление элементов, копирование и перемещение объектов, работу с итераторами и циклический сдвиг элементов с помощью алгоритма `rotate` из стандартной библиотеки C++.

## Функциональность

- Создание пустого динамического массива.
- Добавление элементов в конец массива.
- Автоматическое увеличение вместимости массива.
- Копирование и перемещение объектов.
- Получение итераторов начала и конца массива.
- Циклический сдвиг элементов влево и вправо.
- Вывод элементов массива на экран.

## Структура программы

### Шаблонный класс `Vector`

Класс `Vector` реализует динамический массив, память для которого выделяется вручную с помощью `new[]` и освобождается с помощью `delete[]`.

**Поля класса:**
- `data` — указатель на динамический массив элементов типа `T`.
- `sz` — текущее количество элементов.
- `cap` — вместимость массива, то есть количество элементов, для которых выделена память.

**Конструкторы и деструктор:**

- `Vector()` — создаёт пустой вектор.
- `Vector(const Vector& other)` — конструктор копирования, создающий независимую копию другого вектора.
- `Vector(Vector&& other) noexcept` — конструктор перемещения, передающий владение выделенной памятью от другого объекта.
- `~Vector()` — освобождает выделенную динамическую память.

**Операторы присваивания:**

- `operator=(const Vector& other)` — копирующее присваивание, заменяющее содержимое текущего объекта копией другого вектора.
- `operator=(Vector&& other) noexcept` — перемещающее присваивание, передающее текущему объекту ресурсы другого вектора.

**Методы:**

- `push_back(const T& value)` — добавляет элемент в конец массива. При нехватке вместимости выделяется новый массив увеличенного размера.
- `begin()` — возвращает указатель на первый элемент.
- `end()` — возвращает указатель на позицию сразу после последнего элемента.
- `rotate(int k)` — выполняет циклический сдвиг элементов.
- `print()` — выводит все элементы массива.

Для константных объектов предусмотрены отдельные версии методов `begin()` и `end()`, возвращающие указатели на константные элементы.

## Принцип работы `push_back()`

При добавлении нового элемента проверяется, достаточно ли выделенной памяти.

1. Если `sz` меньше `cap`, элемент добавляется в свободную ячейку.
2. Если вместимость исчерпана, создаётся новый массив.
3. Новая вместимость увеличивается вдвое. Для пустого массива она становится равной `1`.
4. Существующие элементы копируются в новый массив.
5. Старая память освобождается.
6. Новый элемент записывается в конец массива.

Такой подход позволяет не выделять новую память при каждом добавлении элемента.

## Работа метода `rotate(int k)`

Метод выполняет циклический сдвиг элементов массива.

- Положительное `k` сдвигает элементы влево.
- Отрицательное `k` сдвигает элементы вправо.
- Если `k` больше количества элементов, сдвиг сокращается с помощью остатка от деления.
- Если вектор пустой, метод сразу завершает работу.

Для выполнения сдвига используется функция `std::rotate()` из библиотеки `<algorithm>`.

Вызов:

```cpp
rotate(begin(), begin() + k, end());
```

означает, что элементы диапазона переставляются так, чтобы элемент, находящийся по адресу `begin() + k`, стал первым.

## Пример работы программы

Исходный вектор содержит пять элементов: `1 2 3 4 5`.

| Операция | Результат |
|---|---|
| Исходный вектор | `1 2 3 4 5` |
| `rotate(2)` | `3 4 5 1 2` |
| `rotate(1)` | `4 5 1 2 3` |
| `rotate(-2)` | `2 3 4 5 1` |

## Пример результата выполнения

```text
Исходный вектор: 1 2 3 4 5
После rotate(2): 3 4 5 1 2
После rotate(1): 4 5 1 2 3
После rotate(-2): 2 3 4 5 1
```

## Сложность операций

Пусть `n` — количество элементов в векторе.

| Операция | Временная сложность |
|---|---|
| `push_back()` | \(O(1)\) амортизированно, \(O(n)\) при расширении |
| `begin()` | \(O(1)\) |
| `end()` | \(O(1)\) |
| `rotate()` | \(O(n)\) |
| `print()` | \(O(n)\) |
| Конструктор копирования | \(O(n)\) |
| Конструктор перемещения | \(O(1)\) |
